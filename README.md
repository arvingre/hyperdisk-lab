# HyperDisk Lab

🚀 实验性高速外接 SSD 使用方案，适用于多台 macOS 设备的创作工作流。

## 📦 主要功能

- 自动识别插入设备（使用 `launchd` 配置）
- 一键运行项目初始化脚本 `autorun.sh`
- 使用 `rsync` 进行资料同步
- 可运行虚拟机、双系统、视频缓存盘等应用场景

## 🧰 使用步骤

1. 将 SSD 插入 Mac 设备
2. 执行 `autorun.sh` 脚本初始化环境
3. 进入 `MacData/Projects/` 进行日常创作
4. 可选：配置 Time Machine、iCloud、GitHub 等同步方案
